# VIMAAN Demo Guide

**VIMAAN** — *Validated Index for Monitoring Airfares, Automated & National*
Publishes **APIx**, the Real-time Airfare Price Index for India.
SIH 2026 · PS 26056 · MoSPI / DIID

---

## How to Run the Demo

### Quick Start — full stack (2 minutes)

```bash
cd 26056
cp .env.example .env
docker compose up --build
```

| Service | URL | Notes |
|---|---|---|
| Dashboard | http://localhost:3000 | React SPA behind Nginx |
| API | http://localhost:8000 | FastAPI |
| OpenAPI docs | http://localhost:8000/docs | the spec NSO/RBI would consume |
| SDMX-JSON | http://localhost:8000/sdmx/v1/data/APIX/all | statistical-agency exchange format |
| Prefect UI | http://localhost:4200 | the collection & index flows |
| Grafana | http://localhost:3001 | scraper health (admin/admin) |
| MinIO console | http://localhost:9001 | bronze raw-quote evidence |

### Quick Start — frontend only (30 seconds, no backend)

```bash
cd 26056/frontend
npm install
npm run dev
```

- **Normal mode:** `http://localhost:5173` (needs the API at port 8000)
- **Demo mode:** `http://localhost:5173/?demo` — no backend, no Docker, no network. All series, quotes and back-test numbers are client-side fixtures. **This is the mode to present on.**

### Demo Mode Login

Any username/password works. Click **"Enter Demo Mode"** on the login screen. Role defaults to `NSO_ANALYST`, which unlocks every panel including the compliance console.

## What Works in Demo Mode

### 1. APIx Headline (instant, animated)

- 90 days of daily APIx, base **2024 = 100**
- Shaded 95% bootstrap confidence band on every point
- Toggle: **Total fare** vs **Base fare only** (shows how much of airfare inflation is taxes/UDF, not the airline)
- Toggle: daily / weekly / monthly frequency
- Status chips per point: `PROVISIONAL` · `REVISED` · `FROZEN` · `SUPPRESSED`
- Annotated event markers (festival week, a fuel-surcharge step, a capacity-cut week)

### 2. Sector Heatmap

- 20 sectors × 5 lead-time windows (T+1 / T+7 / T+15 / T+30 / T+45)
- Cell colour = % change vs 7-day-ago same cell — the "what got expensive this week" view
- Click any cell → drill into that elementary aggregate: contributing carriers, quote count, imputation flag

### 3. Lead-Time Elasticity Curve

- Mean fare vs days-to-departure, per sector, log-y
- The single most intuitive chart in the deck: shows the T+1 spike that manual monthly collection cannot see
- Overlay two sectors to compare (DEL-BOM trunk vs BLR-HYD short-haul)

### 4. Fare Decomposition

- Stacked area: base fare · taxes & fees · UDF · convenience charge
- Per sector and all-India
- Makes the point that the *published* index tracks total fare because that is what the household pays

### 5. Methodology Console

- Live switch between **Jevons**, **Dutot** and **Carli** on the same underlying quotes — the three lines diverge on screen, and Carli sits visibly above the other two
- Slider for the outlier fence (Tukey `k`) showing index sensitivity
- Toggle imputation method: **cell-mean** vs **naive carry-forward** — carry-forward visibly flattens and drifts the series
- This panel is the answer to "how do we know your number is right?"

### 6. Back-Test Validation

- APIx monthly vs DGCA reference series and vs the CPI air-fare item index, on one dual-axis chart
- Scatter with fitted line, and a metrics strip: **Pearson ρ**, **RMSE**, **MAPE**, **directional agreement %**
- Rolling 30-day window selector

### 7. Compliance Console

- Per-source card: robots.txt posture, `Crawl-delay` honoured, ToS posture, chosen access method, requests today vs nightly cap, last 429, kill-switch state
- "Show robots.txt as fetched" button with the cached copy and its fetch timestamp
- Full request audit log, downloadable as CSV

### 8. Scraper Health

- Quote yield per source per night, block rate, p95 page latency
- Coverage gauge: % of expected cells filled — with the 70% publication threshold drawn on it

## Tech Stack in the Demo

| Layer | What is actually running |
|---|---|
| Collection | Playwright (Python) + Scrapy; `protego` robots gate; Redis token buckets |
| Orchestration | Prefect flows; Celery workers |
| Storage | PostgreSQL 16 + TimescaleDB hypertables; MinIO bronze zone |
| Processing | Polars + pandas; `scipy` for outlier tests; `statsmodels` for seasonality |
| Index math | Pure-Python `indexer/` module, property-tested with `hypothesis` |
| Backend | FastAPI, OpenAPI 3.1, SDMX-JSON serialiser |
| Frontend | React 18 + TypeScript + Tailwind + ECharts (heatmap, band chart) |
| Quality | `pandera` contracts, Great Expectations suite, `pytest` + `vcrpy` fixtures |
| Deploy | Docker Compose; Prometheus + Grafana |

## Rules for the Demo (read this before you present)

1. **Never say "we bypass CAPTCHAs."** Say: "sources that block automated access are served through a licensed API or a statutory data-sharing channel." The compliance console is on screen to back that up.
2. **Never present the seeded back-test numbers as live results.** Say "on the seeded run" or "on our 30-day pilot window."
3. **Always concede the offer-price caveat before a judge raises it.** "These are offer prices, not transaction prices. Here is how we mitigate it, and here is the back-test that measures the residual gap." Conceding it first is worth more than defending it later.
4. If the venue network is down, `?demo` still works. Rehearse in that mode.

# AIAnalyzer (`/ai-analyzer`)

## What It Does
An AI-powered threat analysis page that scores threat severity, predicts attack vectors, and explains its reasoning — all client-side.

## Data Flow
- **HTTP API** — `GET /api/ai/analyze` and `POST /api/ai/analyze` send threat data to the backend and receive analysis results (severity score, confidence, recommended actions, matched signatures).
- **WebSocketContext** — receives `ai_analysis` push events for threats already in-flight; updates the analysis result in place.
- **Local state** — `selectedThreat` (the threat being analysed), `analysisResult` (the response), `isAnalyzing` (loading spinner).
- **Analysis engine** — the component does NOT implement ML client-side. It is a thin UI wrapper around backend endpoints.

## What Is Real
- API endpoints `/api/ai/analyze` exist in the backend and accept/receive real JSON payloads.
- Severity score (0–100), confidence percentage, and threat category are rendered from the API response.
- Recommended action list (block IP, quarantine endpoint, alert SOC, etc.) comes from the backend.
- Matched threat signatures / IOCs (Indicators of Compromise) are displayed from API data.
- WebSocket push for in-flight analysis updates is wired up via `useWebSocket`.
- The "Analyze" button triggers a real POST request.

## What Is Fake
| Aspect | How |
|---|---|
| AI explanation text | Pre-written string templates in the component (`"Threat matches known pattern …"`) not generated by a real LLM. |
| Confidence score animation | CSS transition on a progress bar; the underlying number is from the API but the animation is cosmetic. |
| "Processing" spinner | Standard React loading state; no actual ML progress indicator. |
| Sample threat selector | Dropdown of pre-loaded threat IDs for demo purposes; in production this would be a live threat list. |
| Historical analysis cache | `analysisHistory` array is client-side only and lost on refresh. |

## Verdict
~85% real. The analysis pipeline (API endpoints, WebSocket pushes, data rendering) is fully implemented. The only fabricated elements are the UI explanation strings (not LLM-generated prose) and the demo threat selector.

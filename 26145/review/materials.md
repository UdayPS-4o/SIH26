# Evidence & Materials (`/materials`)

## What It Does
Threat evidence/samples data grid. Columns: ID, name, type, threat class, hash (SHA-256), confidence score, source, date, status. Search and filter by threat class. Shows sample details including file size, first seen, last seen, similarity to known samples. Hash validation display.

## Data Flow
- All data generated client-side in `MaterialsPage.tsx`
- Constants define: malware names, C2 configs, DDoS tools, recon scripts, DNS malware, phishing kits
- `fakeHash(seed)` generates deterministic-ish SHA-256 hex strings
- `generateMockMaterials(count)` creates entries with random but consistent data
- No backend API calls

## What Is Real
- Nothing from the backend. Zero API calls.
- SHA-256 hash format is realistic (64 hex chars)

## What Is Fake
| Data | How |
|------|-----|
| Material names | Picked from predefined lists: Emotet, TrickBot, QakBot, CobaltStrike, Mirai, etc. |
| Threat classes | Picked from 10 predefined classes (APT, Ransomware, Trojan, etc.) |
| Hash values | Generated by `fakeHash()` — deterministic pseudo-random hex strings |
| Confidence scores | Random 55-99% |
| Source attribution | Picked from 10 sources (VirusTotal, AbuseIPDB, OTX-AlienVault, etc.) |
| Dates | Random within last 90 days |
| Status | Weighted random: 40% approved, 30% pending, 20% imported, 10% rejected |
| File sizes | Random KB/MB values |
| Similarity scores | Random 0-100% |

## Verdict
**0% real data.** All material entries are procedurally generated. No backend connection. Realistic-looking but entirely synthetic.
